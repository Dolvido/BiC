What is learnedA trained neural encoder compares object images. Teaching adds visual exemplars to a persistent association bank; it does not update the encoder's weights.
What this demonstratesRapid association and recall under changing views, inspired by fast episodic memory. This mode is a separate perception-and-memory experiment.
What the replies meanConversation uses the listed commands and interface templates. Similarity scores are not probabilities. Ambiguous or unfamiliar objects can return no match.
