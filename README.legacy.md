BiC is a small Python research system with **13 separately parameterized core neural networks**, connected through explicit brain-inspired pathways. It learns restricted English, acts in a miniature pixel desktop, and follows spatial instructions about objects you teach it.

## Install and start

On Windows, extract the ZIP and open PowerShell in the project folder:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m brain_in_computer doctor
.\.venv\Scripts\python.exe -m brain_in_computer launch --open-browser
```

On Linux, macOS, or WSL, create the environment with `python3 -m venv .venv`, then use `.venv/bin/python` in place of the Windows interpreter above. CPU is the default. Leave the terminal open; Ctrl+C stops both servers.

| Lab | Address | First interaction |
|---|---|---|
| Computer | [Open computer lab](http://127.0.0.1:8765) | `hello`, `click the red button`, `what did you click`, `type hi` |
| Teaching | [Open teaching lab](http://127.0.0.1:8766) | Select an object, teach `dax`, change the scene, then `find "dax"` |

In the teaching lab, also try:

```text
click the object left of "dax"
click the object right of "dax"
click the object above "dax"
click the object below "dax"
```

The objects occupy a 2×2 grid. An impossible direction, untaught name, absent object, or ambiguous match should produce STOP. These decisions are learned and can be wrong. **Change scene** varies existing objects; **Generate new objects** creates different objects while retaining saved names.

Taught associations persist in `runs/personal-memory.json`, with a companion scene file. The same launch command restores them. Ordinary interaction stores examples but does not run an optimizer. Names are exact, case-sensitive memory addresses; the quoted name becomes `<name>` before instruction comprehension. Direction meanings, actions, and action replies are learned; teaching acknowledgments and identification use interface text.

Both labs load the same released computer/language weights, independently in two processes. [PROJECT_GUIDE.md](docs/PROJECT_GUIDE.md) explains single-lab launch, custom memory files, ports, GPU selection, and troubleshooting. `doctor` checks dependencies and file presence; actual checkpoint compatibility is checked when a lab starts.

## What changed

**Replay and retention.** Targeted rehearsal revisits older desktop lessons while continuing regional-memory practice. Old test wording used for this repair is explicitly reported as a restoration diagnostic. Separate new sentences and new object identities assess transfer; see [V06_RESULTS.md](docs/V06_RESULTS.md).

**Learning associations into shared weights.** A new 56,824-parameter byte/GRU recall network learns taught name-to-visual associations from rapid exemplar memory. Its saved inference state contains shared weights and a known-name set, with no per-name visual vector table. Visual comparisons still enter the existing hippocampal pathway before the motor network acts.

Across two seeds and 32 taught names per seed, rehearsal preserved 99.34% action accuracy on both old and new associations. Without rehearsal, old-association accuracy fell to 57.03%. Random or erased recall weights selected none of the valid targets. These are familiar taught identities seen in new renderings and arrangements, not unseen identity learning.

This experimental recall API is available in [consolidation.py](brain_in_computer/consolidation.py), with runnable examples and evidence in [CONSOLIDATION.md](docs/CONSOLIDATION.md). The live teaching interface continues to use rapid exemplar memory; it does not silently train the experimental network. We have demonstrated transfer into a shared recall network, not full biological systems consolidation or reduced memory cost.

**A clearer project.** `config/checkpoints.json` selects the current release. `doctor` and `launch` remove the need to remember checkpoint paths. Historical checkpoints and reports remain in place so earlier results retain their provenance.

## Scope and home computation

The released controller has about 558,000 parameters; experimental neural recall adds about 57,000. [HOME_COMPUTE.md](docs/HOME_COMPUTE.md) records earlier CPU optimizer benchmarks through 175.7 million parameters. That larger workload is not the trained model shipped here. The [local English study](docs/ENGLISH_FRONTIER_RESULTS.md) now includes an RTX 5080 optimizer benchmark and actual GPU training; a home-compute ceiling has not been established.

Biological inspiration guides modular specialization, communication, rapid association, and rehearsal. Training uses global backpropagation. The system does not simulate an anatomical brain or demonstrate general intelligence. Its evidence concerns synthetic objects, five spatial relations, restricted English, and eleven miniature-desktop actions. Open-ended conversation and general operating-system use remain unproven. A local LLM could supply better verified lessons, but it would not automatically give BiC the teacher's capabilities.
