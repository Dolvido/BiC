# Shared objective transition results

Removing the shared-state auxiliary objective did not pass the predeclared acquisition-effect screen. The zero-weight branch finished **2.0833 percentage points below control** across the 12 equally weighted complementary acquisition cells: **fit -7.5000 pp, development +3.3333 pp**. Neither branch met the absolute acquisition, original capability, or retention requirements; neither is eligible for adoption. The retained home learner remains **9,328**, separate from these research descendants at **15,592**.

This report reads the already verified independent JSON report; it does not rerun raw scoring, model inference, training, lesson generation or tutor calls. All counts below are native action decisions and freely generated English replies, without auxiliary predictions used as policy answers.

## Comparison and evidence

Both branches started from the exact same curriculum checkpoint at 13,000, with the same full incoming weights, AdamW moments and individual step counters, evidence, and historical work. Control explicitly continued auxiliary weight 0.3; zero explicitly changed 0.3 to 0. Both consumed the same ordered 648-bundle curriculum four times, at the unchanged learning rate 0.0003 and global gradient clip norm 1. Each completed 2,592 updates. Evaluation endpoints were relative updates 0 / 648 / 1,296 / 2,592, corresponding to lifetime 13,000 / 13,648 / 14,296 / 15,592.

This tests objective removal conditional on this inherited optimization history. Removing a loss changes the total gradient and possible clipping, so even a positive result would not uniquely establish harmful representational interference. Retaining an entity-value target across rule changes does not prove that other directions of the same context vector cannot encode those rules.

## Interpretation and next shared learning decision

The prewritten decision memo calls for separating continued acquisition, objective effects, transfer and retention. Here, the auxiliary-removal screen failed, but that does not prove the auxiliary objective is universally beneficial. The zero arm's better development binding and worse practiced acquisition are a tradeoff under one parent, one sequence and one optimization history. Continued exact-fit revision improvement and declining native training loss argue against declaring learning exhausted; the unstable development binding and failed retention argue against treating more practice as automatically safe. Near-zero basis composition/sequence still prevents a claim of general reusable program learning.

The selected next research direction is a **matched same-parent learning-rate continuation from this study's final control at 15,592**, comparing unchanged **0.0003** with **0.0001**, with auxiliary weight **0.3 in both**, the same complete curriculum, incoming AdamW history, and exposure count. The planned comparison is four further 648-update passes per arm, with endpoints 0 / 648 / 1,296 / 2,592. This is a chosen research question, not a report of a launched or completed experiment; no result or adoption is implied here.

The question is whether a smaller step size improves stable shared acquisition and retention across families while preserving continued practice gains. Current instability motivates the test but does not establish that the current rate is excessive. The earlier 0.0003 versus 0.003 evidence also had fit/transfer tradeoffs, so lower is not assumed better. AdamW's effective per-update decay also scales with the rate; this would estimate a rate-transition effect under the same optimizer, not an isolated proof about gradient noise. The transition must explicitly preserve full incoming state and record the changed recipe rather than silently relabel the old continuation.

No family-specific allocation, answer patch, architecture change, fresh teacher material or cache integration follows from these results. Any efficiency change must show end-to-end benefit before a learning-per-hour claim. Absolute acquisition, learned-program transfer and retention remain distinct requirements. Repeated development observations, a finite grammar, one inherited seed/history and finitely many endpoints limit generalization; these trials do not establish a home-computer capability ceiling. Neither research branch replaces the retained home learner at 9,328.
