# Persistent recall through the regional brain

V0.5 connects taught visual associations to the same regional controller and
language networks used by the miniature computer lab. The controller receives
evidence for all four objects, interprets an instruction, and produces an action
through its existing motor cortex. This is a bounded experiment in using memory
to guide behavior on a fixed two-by-two board.

## Launch and teach

From the extracted project directory, after installing its dependencies:

```bash
python -m brain_in_computer memory-serve --checkpoint runs/associative/encoder.pt --regional-checkpoint runs/regional-memory-v05/checkpoint.pt --memory runs/personal-memory.json --port 8766 --threads 1
```

Open [localhost:8766](http://127.0.0.1:8766). Select an object, enter a name such as
`dax`, and press **Teach**. Change the scene to vary the objects' appearance and
positions. The **Find** button uses the regional controller when this checkpoint
is loaded. The command interface accepts instructions such as:

```text
find "dax"
click the object left of "dax"
click the object right of "dax"
click the object above "dax"
click the object below "dax"
```

Teaching stores visual exemplars without optimizing network weights. Restarting
with the same memory path reloads them. The companion `.scene.json` file belongs
to the renderer and preserves the object identities needed to reconstruct the
scene. Those identifiers are not inputs to the neural policy.

Quoted action commands receive a freely generated byte response from the
language decoder. Teaching acknowledgments, help, and **What is this?** retain
the explicit interface templates and visual matching behavior described in
[ASSOCIATIVE_MEMORY.md](ASSOCIATIVE_MEMORY.md). They should not be counted as
neural conversation results.

The computer lab can load the **same v0.5 checkpoint**, selecting its shared
computer/language networks:

```bash
python -m brain_in_computer computer-serve --checkpoint runs/regional-memory-v05/checkpoint.pt --port 8765 --threads 1
```

This makes old desktop-task retention observable with the updated weights.
Loading the historical v0.4 checkpoint instead would test a different model.

## What the instruction means

The board has four cells in row-major order:

| Row | Left column | Right column |
|---|---|---|
| Top | Action 0 | Action 1 |
| Bottom | Action 2 | Action 3 |

`find` selects the named object. The other four instructions select its immediate
neighbor in the stated direction. Directions do not wrap around the board. The
training target is **STOP, action 10**, when the neighbor would fall outside the
board, the name is untaught, the named object is absent, or multiple copies make
the referent ambiguous.

STOP is a learned output. Inference does not apply a hand-written cosine
threshold to choose or reject an object. Mistakes remain possible. The shared
motor cortex still has eleven outputs because the old desktop uses typing
actions 4–9; if one is produced on this board, it is reported as an unsupported
action rather than silently reclassified as a successful STOP.

## Actual information flow

| Component | Input and operation | Output used by the system |
|---|---|---|
| Name parser | Extract exactly one JSON-quoted name, then replace it with `<name>` in the utterance | An exact symbolic memory address and a normalized instruction |
| Persistent exemplar bank | Retrieve the embeddings previously stored under that address | Taught visual examples and a known-name flag |
| Frozen glyph encoder | Encode the four current RGB object crops | Four normalized visual embeddings |
| Similarity calculation | Compare every candidate with every exemplar for the named object; retain each candidate's best similarity | All four raw cosine scores, without choosing an index |
| Learned recall adapter | Transform the four scores and the known-name flag | A vector in the regional hidden space |
| Hippocampus | Add that vector to within-episode recall before the existing learned output transformation | Recalled evidence for prefrontal cortex and basal ganglia |
| Regional controller | Combine recall, the learned instruction representation, and recurrent regional activity | Existing motor-cortex action logits |
| Language production | Read final prefrontal, parietal, and hippocampal activity | Autoregressively generated response bytes |

The name parser does not identify the requested direction or choose an action.
Directions are learned by the language/controller networks. However, a new name
such as `dax` is still an exact symbolic address: masking it as `<name>` means
this experiment does **not** demonstrate acquiring that word's meaning in the
language-network weights. Name matching is case-sensitive. Quotation marks and
backslashes inside names use JSON escaping.

The fixed board supplies already separated 32×32 RGB crops. Automatic object
detection, changing board geometry, arbitrary mouse coordinates, and general
screen understanding are outside this task. Glyph identity numbers and relation
labels exist in the procedural teacher to render scenes and score outcomes;
they never enter policy observations.

Recall mode runs two regional updates by default. Its ordinary visual, auditory,
and body channels are zero: the object-derived evidence enters through the
declared hippocampal input. Consequently, silencing visual cortex is not a
blindness test for this mode. All thirteen regional networks still participate
in their existing execution schedule, but participation does not establish that
every region is necessary for these tasks.

Omitting the optional recall input preserves the old computation and adds no
parameters to the existing core. A CPU compatibility probe compared the original
v0.4 package with the new implementation, using the same v0.4 weights and input
batch; every returned tensor matched exactly. See
[v05_compatibility.json](../experiments/v05_compatibility.json) for the scope and
hashes. This is a fixed probe, not a guarantee across hardware and numerical
formats. The v0.5 regional checkpoint format requires float32 networks.

## Training, controls, and retention

The experiment freezes its glyph partitions, utterance templates, sampling
seeds, and model-selection rule before training. New training, development, and
sealed glyph identities exclude every identity in the earlier encoder's
training, validation, initial development test, and final test. Normalized
utterance templates are also disjoint between the new partitions. All five
relations and the appearance-generating family occur in training; the test
therefore measures transfer to new glyphs and phrasing within this family.

Half the examples require a valid cell selection. The other half is evenly
divided among untaught names, absent objects, ambiguous objects, and board
boundaries. Always stopping therefore scores 50% overall. Valid selections,
individual STOP causes, actions, and exact replies must be assessed separately.
The primary evaluation uses one taught example per queried identity; it does
not establish behavior for arbitrary numbers of exemplars or large name banks.

Two training arms start with the same v0.4 computer weights and recall-adapter
initialization. They receive the same new-task batches and wording samples. One
also rehearses old desktop examples. The matched comparison uses the same count
of new-task updates; replay adds old examples and computation, so it is not an
equal-total-compute comparison. A separate development-selected checkpoint is
chosen using both new-task action accuracy and old-task joint accuracy. Sealed
evaluation does not select the checkpoint.

| Control recorded in the report | Intervention and interpretation |
|---|---|
| `blank_memory` | Zero the entire projected recall vector, removing scores, availability, and adapter bias |
| `hippocampus_lesion` | Silence within-episode and external hippocampal recall together |
| `temporal_language_lesion` | Remove the instruction pathway entering the regional core |
| `blank_language` | Replace the utterance with an empty string |
| `zero_encoder` | Zero the cached similarity scores while retaining the known-name flag; this is a zero-evidence control, not a raw-image blanking experiment |
| `shuffled_memory` | Permute the four score positions while leaving the target fixed; this tests score-to-cell correspondence, not a shuffled exemplar bank |

These acute interventions test dependence of a fitted system. They do not show
that the same architecture is superior to every alternative, or that the named
biological regions have equivalent functions. The experiment has one training
seed per arm. Its exact protocol is in
protocol.json (archive reference: `../runs/regional-memory-v05/protocol.json`); quantitative results
are in [V05_RESULTS.md](V05_RESULTS.md).

## Biological motivation and remaining boundary

Fast exemplar binding and slower representation learning provide two distinct
timescales of learning. Rehearsing prior examples tests whether revisiting older
experience helps a changing controller retain useful behavior. These are
engineering analogies to association and replay.

The encoder remains frozen, stored associations remain explicit vectors, and
training uses global backpropagation. Nothing here transfers a taught name from
the external bank into cortical weights, implements sleep, simulates neurons,
or establishes general intelligence. Two recurrent updates are algorithmic
steps, not a physiological timescale. A subsequent consolidation experiment
would need to test retained knowledge after removing its external memory,
while controlling interference and preserving independent held-out tasks.

Persistent memories remain bound to exact encoder weights. Loading a bank with
an incompatible encoder is rejected rather than silently reusing stale
embeddings. The controller checkpoint includes the frozen encoder and shared
computer/language weights; the user's taught names remain in the separate JSON
memory file.
