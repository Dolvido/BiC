# Complementary operation orders with broad rehearsal

Status: prospective implementation design, not an executed experiment.

The completed chapter-order comparison did not improve held-out composition.
Both arms had weak complete multi-rule acquisition; measured training binding
was also weak. Their prior-definition rehearsal already taught copy followed by
destination advancement. Therefore the next test broadens composition coverage,
without attributing the failure to unseen semicolon syntax or a proven model
defect. Preserve the previous result and all original test banks.

Use the same operations across color, count and switch: C copies source to
destination, S advances source once, and D advances destination once. Introduce
this compact complementary menu in both two-word binding and revision lessons:

| Counterfactual contrast | Intended coverage |
|---|---|
| CD / DC | Order and overwrite |
| SD / DD | Source versus destination participation |
| SS / DS | Repetition versus changing both arguments |
| DCD / CDD | Three-clause order |
| SSD / SDD | Accumulated changes across arguments |

Keep exact SC, CS, SCS and CSS programs absent from every training recipe. The
existing development panels retain those combinations. Apply the same menu to
all three families, vary names and initial values, shuffle definition order,
swap source/destination application roles and test both arguments, unknown
entities and pre-revision state. Training labels come from separate typed and
visible-English interpreters. Neither teacher text nor evaluator predictions
are accepted as ground truth. All new rows require an honest new provider
version and preserve input-versus-supervision separation at inference.

This is a structural program holdout. Functional novelty is family-dependent:
SD and DS commute; DC and C are equivalent. For switches, CSS equals C, while
SCS equals CD and DCD. These equivalences must be documented, and equivalent
programs must not be used as opposite-answer counterfactual members. The five
proposed pairs differ in destination values for the declared known states;
both interpreters must still verify every generated anchor. Value ranges must
keep count states within the existing finite domain. Check text/context sizes
against the unchanged model limits before admitting training data.

The proposed comparison starts both arms from the same exact update-9,760
research checkpoint and full AdamW, with the retained update-9,112 reference
kept separate. Hold architecture, learning rate, objectives and family weighting
fixed. At a fixed 648-update endpoint, the control receives 216 original basis,
108 prior-definition and 324 broad rehearsal updates. The candidate replaces
180 of those basis updates with the complementary menu, retaining 36 atomic
basis updates. All ten composition contrast/mode cells receive 18 updates;
the six atomic contrast/mode cells receive six. Prior-definition and broad
rehearsal remain identical and interleaved throughout both arms. Declare the
change in example distribution and text-token cost; equal optimizer updates
do not imply equal compute or identical learning content.

Before execution, finish the additive provider, immutable data preparation and
runner protocol, then verify their correctness with focused checks. Do not
modify frozen sources or relabel old recipes. The final protocol must set one
inclusive local compute allowance, fixed evaluation endpoints and explicit
failure accounting before looking at new results.

Evaluate prospectively selected actual training rows, fresh-name examples of
trained combinations, the unchanged reserved combinations and old-skill
retention. Use native actions and freely generated replies, with complete
counterfactual pairs primary. Preserve all declared endpoints and exact restart
evidence. Improvement confined to practiced compositions establishes acquisition,
not transfer. Retention must be checked against both the research parent and
the retained reference. No automatic adoption follows a small development lead.

The objective-weight and concentrated-rehearsal controls remain hypotheses for
later decisions, not simultaneous changes in this experiment. Current query
action loss already excludes acknowledgements from its class-balanced mean;
both action and reply mistakes contribute to weak binding. Source review alone
does not establish harmful auxiliary gradients or inadequate model capacity.
