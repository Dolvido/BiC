# Research documentation

The top-level [README](../README.md) is the current research report and public
entry point. Public demo (archive reference: `PUBLIC_DEMO.md`), public evidence (archive reference: `PUBLIC_EVIDENCE.md`)
and [release validation](RELEASE_VALIDATION.md) describe what ships in this repository.

The other documents preserve earlier designs, protocols, results and handoffs.
Read their dates, checkpoint identities and stated scope: they describe different
learners and stages, not a single combined capability.

References to `runs/` identify the author's local experimental archive. That
archive is not part of the repository. In this distribution, unavailable file
links are rendered as archive paths. Historical SHA-256 values identify original
frozen research artifacts; documentation links may have been adapted for public
distribution. The public aggregate evidence is a documented projection, not the
complete raw experiment or a promise of exact fresh-run replication.

The home-training guides require the initialized local campaign and its full
history. A source clone alone cannot resume that campaign. The public CPU demo
has a separate inference-only checkpoint and does not advance the home learner.
