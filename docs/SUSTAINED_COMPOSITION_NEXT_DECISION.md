# Decision after the sustained composition trial

This decision plan is written while the fixed trial is running, before reading
its new endpoint scores. It does not alter the frozen protocol or its acceptance
rules. The question is which general learning mechanism to test next, not which
individual example to repair.

## Read the result in this order

1. Authenticate completion, exact workloads, full-state restores and all raw
   scores with the independent reader. Use the completion marker for inclusive
   worker time. A partial run does not establish a completed paired comparison.
2. Inspect the full acquisition trajectory in every family on both practiced
   and development examples. Complete opposite-answer pairs are primary;
   destination queries distinguish execution from remembering unchanged values.
3. Inspect structural-program transfer, action/reply agreement and all three
   retention references. These development banks have already been observed;
   improvement is not a fresh audit or proof of general English understanding.
4. Report gains together with total elapsed training time, repeated exposures
   and memory cost. Faster execution alone does not demonstrate better learning.

## Conditional next action

- If practiced acquisition remains weak, distinguish inadequate practice from a
  flat trajectory before modifying the model. Positive trajectories can justify
  a separately fixed continuation; they cannot justify claiming an architectural
  ceiling. If the trajectory remains poor across subjects, first compare the
  current objective with removal of state-auxiliary gradients into the language
  encoder. This is a hypothesis test, not a diagnosed cause.
- If practiced acquisition succeeds but structural transfer remains weak, the
  next curriculum should vary reusable procedures and contexts while keeping
  independently checked semantics. Increasing repeats of exact rows does not
  test transfer by itself. Preserve whole-program holdouts and identify
  functional equivalences between programs in each domain.
- If acquisition and transfer improve but retention fails, treat that as a
  learning-versus-retention tradeoff. Compare a common retention mechanism or
  replay policy across all subjects; do not patch whichever single cell lost
  the most points. The existing home learner remains the usable continuation.
- A branch passing this research screen still needs comparison against the
  then-current home checkpoint and a prospective fresh evaluation before any
  adoption claim. The trial's historical update-9,112 reference is not the
  current update-9,328 home learner.

## Smallest next mechanism test

The existing state decoder predicts entity values from the same contextual
representation used by native actions and replies. Rule definitions and
revisions can change rule meaning without changing those entity targets. The
representation can still encode both; target invariance alone does not prove
gradient interference.

An explicit objective transition can test auxiliary influence without adding
parameters. Weight 0.3 versus weight zero is already supported by the kernel;
the current continuation recipe correctly rejects changing it silently. A new
transition must preserve and authenticate all incoming weights and optimizer
state, declare the changed objective, and give both arms the same examples,
updates, endpoints and retention checks. A context-detached auxiliary decoder is
a more specific alternative that keeps training the decoder while removing its
gradient contribution to the encoder. These alternatives are distinct studies,
not interchangeable labels for an existing continuation.

Only after that evidence warrants an architectural test, compare a learned
latent workspace carried between turns with an otherwise matched reset
workspace. Both need the same new parameters and initialization, unchanged
native text inputs and outputs, and no oracle rule/state inputs. Existing static
retrieval and repeated-reading results do not establish whether learned writes
would help the current, more extensively trained learner.

The local LLM remains external. Its useful contribution must appear as better
independent acquisition or retained transfer per compute hour, beyond simply
producing a valid curriculum request. Offline operation, bounded resource use,
honest provenance and preservation of useful prior abilities remain requirements.
